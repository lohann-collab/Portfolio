# Portfolio Lohann — version développeur

## Fichiers
- `index.html` : portfolio principal.
- `status/index.html` : page d’état des services.

## Déploiement GitHub Pages
1. Décompressez l’archive.
2. Envoyez `index.html` à la racine du dépôt GitHub Pages.
3. Envoyez le dossier `status/` à la racine également.
4. Faites un commit. La page d’état sera disponible à `/status/`.

Le site est statique, responsive, sans étape de compilation. Les images des bannières sont chargées depuis Discord CDN.
